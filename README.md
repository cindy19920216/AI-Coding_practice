# 한국 주식 테마 감성 분석 → 핵심 관련주 발굴 파이프라인

> 텔레그램 채널 데이터 기반으로 월별 주도 테마를 추출하고,  
> Google 뉴스 감성 분석 + XGBoost로 테마에 가장 민감하게 반응하는 관련주를 자동 발굴합니다.

---

## 핵심 아이디어

```
"2차전지 관련 뉴스가 긍정적이다" (감성 분석)
         ↓
그 시점에 실제로 주가가 올랐나? (yfinance 검증)
         ↓
긍정 뉴스 + 주가 상승이 일치하는 종목 = 핵심 관련주
         ↓
"이 테마에서 가장 민감하게 반응하는 기업은 A, B, C다" (XGBoost 랭킹)
```

---

## 전체 흐름 (7 STEP)

```
STEP 1  텔레그램 CSV 로드
        └─ 10개 채널 메시지에서 월별 TOP5 테마 추출
           노이즈 복합어 제거 후 순수 테마 언급만 카운트

STEP 2  Google 뉴스 자동 수집
        └─ 월별 TOP5 × 12개월 = 최대 60개 쿼리
           pygooglenews 사용, API키 불필요

STEP 3  한국어 금융 키워드 감성 분석
        └─ 긍정/부정 키워드 사전 기반 룰 분석
           결과: 긍정 466건 / 부정 149건 / 중립 1,643건 (총 2,258건)

STEP 4  yfinance 주가 데이터 수집
        └─ KRX300 기준 시총 상위 300종목만 대상
           FinanceDataReader 기반 (KOSPI+KOSDAQ 시총 상위 300종목)

STEP 5  감성점수 + 주가 수익률 병합
        └─ 뉴스 감성(t일) → 익일 주가 수익률(t+1일) 매핑
           3일·5일 이동평균 감성점수 추가

STEP 6  XGBoost 예측 (TimeSeriesSplit 5-fold)
        └─ 익일 주가 상승 여부(up_next) 분류
           평균 AUC: 0.5833

STEP 7  최종 관련주 랭킹 + 시각화 6종
        └─ 종합점수 = 상승확률(60%) + 감성-수익률 상관관계 정규화(40%)
```

## 시사점

### 1. 통신주가 자꾸 상위에 나오던 이유

"통신"이라는 단어가 통신주 외에도 다양한 맥락에서 등장하기 때문입니다.

| 메시지 출처 | 통신 복합어 예시 |
|------------|----------------|
| 스페이스X 관련 | 위성통신, 통신위성, 우주통신 |
| 로봇·IoT 관련 | 통신모듈, 통신칩, 무선통신 |
| HBM·반도체 관련 | 광통신, 데이터통신 |

**노이즈 제거 효과:**

| 월 | 원본 언급 | 노이즈 제거 후 | 제거율 |
|----|-----------|---------------|--------|
| 2026-03 | 85건 | 58건 | 32% |
| 2026-04 | 76건 | 53건 | 30% |
| 2025-09 | 31건 | 15건 | 51% |

→ 2026-03 1위 → 3위 / 2026-04 1위 → 5위로 조정됨  
→ 실제 SKT·KT·LGU+ 직접 언급은 유지 (2026-03/04에 배당 매력·방어주 수요 실제로 존재)

### 2. KRX300 필터 전후 비교

| 테마 | 전체 종목 | KRX300 필터 후 | 주요 제거 유형 |
|------|-----------|---------------|----------------|
| 로봇 | 70개 | 12개 | 소형 로봇 부품주 |
| 화장품 | 91개 | 14개 | 소형 ODM·원료주 |
| HBM | 33개 | 9개 | 소형 장비·소재주 |
| 게임 | 30개 | 8개 | 소형 모바일 게임사 |
| 통신 | 3개 | 3개 | 변동 없음 (전부 대형주) |

### 3. 대형주는 감성 추세, 소형주는 가격 모멘텀

- **소형주 포함 이전**: `return_1d`(당일 주가 모멘텀) 피처 중요도 1위
- **KRX300 대형주 기준**: `sentiment_ma3`(3일 감성 추세) 피처 중요도 1위

대형주는 기관·외국인 매매 비중이 높고 뉴스 반응이 추세적으로 누적되기 때문에  
감성 이동평균이 단기 주가 모멘텀보다 예측력이 높게 나타납니다.

### 4. 신규 테마: MLCC (2026-05)

2026년 5월에 처음 상위 진입한 MLCC 테마에서 **대주전자재료**의 감성-수익률 상관관계가 **0.77**로 전체 92개 종목 중 가장 높음.  
AI 서버·전장(車) 수요에 연동된 MLCC 수요가 뉴스 감성과 주가 반응이 강하게 일치하는 구조임을 시사합니다.

## 설정값 변경 (`STEP 0`)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `TOP_N` | 5 | 월별 추출할 상위 테마 수 |
| `BATCH_SIZE` | 50 | 테마별 최대 뉴스 수집량 |
| `KRX300_TOP_N` | 300 | KRX300 근사치 종목 수 (KOSPI+KOSDAQ 시총 순) |
| `STOPWORDS` | 증권, 투자, 시장... | 테마 집계에서 제외할 단어 |
| `THEME_NOISE_WORDS` | 은행·통신 | 복합어 제거 노이즈 사전 |

### 노이즈 사전 추가 방법

특정 테마명이 다른 맥락에서 복합어로 많이 등장하면 `THEME_NOISE_WORDS`에 추가:

```python
THEME_NOISE_WORDS = {
    '은행': ['중앙은행', '한국은행', ...],      # "은행" 노이즈
    '통신': ['위성통신', '통신모듈', ...],      # "통신" 노이즈 (추가됨)
    '에너지': ['신재생에너지', '에너지전환', ...], # 예시: 추가 가능
}
```

## 분석 방법론

### 종합점수 계산식

```
종합점수 = 상승확률 × 0.6 + 감성-수익률 상관관계(정규화) × 0.4
```

- **상승확률**: XGBoost가 예측한 익일 상승 확률의 종목별 평균
- **감성-수익률 상관관계**: 긍정 뉴스가 나온 다음날 실제로 주가가 올랐는지의 역사적 일치율

### KRX300 근사 방법

pykrx 1.2.4에서 `get_index_portfolio_deposit_file` API가 KRX 서버 변경으로 작동하지 않아  
`FinanceDataReader.StockListing('KOSPI'+'KOSDAQ')` 기반 시총 상위 300종목으로 근사합니다.

| 구분 | 방법 | 비고 |
|------|------|------|
| 이상적 | pykrx KRX300 index | pykrx 1.2.4에서 API 깨짐 |
| 현재 사용 | FinanceDataReader 시총 상위 300 | 최소 시총 약 1.32조원 기준 |

### 감성 분석 방식

API 없이 동작하는 한국어 금융 키워드 사전 방식

- **긍정 (25개)**: 상승, 급등, 호재, 수주, 흑자, 돌파, 신고가, 어닝서프라이즈 등
- **부정 (23개)**: 하락, 급락, 악재, 적자, 소송, 파산, 어닝쇼크, 신저가 등
