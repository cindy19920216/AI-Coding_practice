# 한국 주식 테마 감성 분석 → 핵심 관련주 발굴 파이프라인

> **Google + 네이버 뉴스 감성점수**로 월별 주도 테마를 선정하고,  
> 텔레그램 시장반응 피처 + **Gemini LLM 감성 분석** + XGBoost(12개 피처)로  
> 테마에 가장 민감하게 반응하는 관련주를 자동 발굴합니다.

---

## 핵심 아이디어

```
뉴스 감성점수가 높은 테마 선정 (공식 정보 기반 → 학술적 근거 강화)
         ↓
"2차전지 관련 뉴스가 긍정적이다" (Gemini LLM 문맥 감성 분석)
         ↓
그 시점에 실제로 주가가 올랐나? (yfinance + 거래량·52주·KOSPI 상대강도)
         ↓
텔레그램 언급량이 과열 전 선행했나? (tg_news_ratio 과열 감지)
         ↓
"이 테마에서 가장 민감하게 반응하는 기업은 A, B, C다" (XGBoost 랭킹)
```

---

## 전체 흐름 (9 STEP)

```
STEP 1  텔레그램 CSV 로드 → 후보 테마 추출 (TOP10/월)
        └─ 테마 선정 목적 아님 → 뉴스 수집 대상 결정용
           KRX 매칭 3개 미만 테마 자동 제거 (외국명이어도 관련주 있으면 유지)

STEP 2  Google + 네이버 뉴스 병행 수집
        └─ 월별 TOP10 × 12개월 = 최대 120개 쿼리
           BATCH_SIZE=200 (상한선 설정값, pygooglenews 실제 반환 최대 50건/쿼리)
           Google + 네이버 중복 제거 후 합산
           ※ 현재 results: v1 데이터 재사용 (60쿼리 × 평균 37건 = 2,258건)

STEP 3  Gemini LLM 감성 분석
        └─ 키워드 방식(중립 72%) → Gemini LLM 문맥 이해(중립 18%)
           모델: gemini-2.0-flash-lite / 배치 20건

STEP 4  뉴스 감성점수 기반 TOP5 테마 최종 선정 ★ 핵심
        └─ 기존: 텔레그램 언급 빈도 → 변경: 공식 뉴스 감성점수
           점수 = 긍정비율(60%) + 정규화 합계(40%)
           학술적 근거: 공식 정보 기반 테마 선정

STEP 5  텔레그램 언급량 피처 생성 (역할 변경: 선정→피처)
        └─ tg_mention_count  : 일별 언급량
           tg_mention_ma3    : 3일 언급 추세
           tg_news_ratio     : 텔레그램/뉴스 비율 (과열 감지)

STEP 6  yfinance 주가 + KOSPI 수집
        └─ KRX300 기준, 3개 미만 시 KRX500까지 자동 확장
           TICKER_MAP: 스페이스X·화이자·두나무 관련주 수동 보완
           신규 피처: volume_change / high_52w_ratio / kospi_relative

STEP 7  감성 + 텔레그램 + 주가 전체 병합
        └─ 뉴스 감성(t일) → 익일 주가 수익률(t+1일) 매핑
           3일·5일 이동평균 감성점수 추가

STEP 8  XGBoost 예측 (TimeSeriesSplit 5-fold, 12개 피처)
        └─ 뉴스 피처 4개 + 주가 기술 5개 + 텔레그램 3개
           익일 주가 상승 여부(up_next) 분류

STEP 9  최종 관련주 랭킹 + 시각화 7종
        └─ 종합점수 = 상승확률(60%) + 감성-수익률 상관관계 정규화(40%)
           tg_news_ratio 히트맵 (과열 감지) 포함
```

## XGBoost 피처 구성 (12개)

| 그룹 | 피처 | 중요도 | 설명 |
|------|------|--------|------|
| 뉴스 감성 | `sentiment_ma3` | 0.096 | 3일 이동평균 감성점수 |
| 뉴스 감성 | `sentiment_score` | 0.096 | Gemini LLM 일별 평균 감성점수 |

| 텔레그램 | `tg_news_ratio` | 0.086 | 텔레그램/뉴스 비율 (과열 감지) |
| 뉴스 감성 | `news_count` | 0.086 | 일별 뉴스 기사 수 |
| 주가 기술 | `kospi_relative` | 0.076 | 코스피 대비 상대강도 (초과수익률) |

## 시사점

### 1. 텔레그램 피처 도입 효과 (v2 핵심 개선)

텔레그램의 역할을 **테마 선정 도구 → 시장 선행 신호 피처**로 전환:

```
tg_mention_ma3   → 피처 중요도 3위 (0.095)
tg_mention_count → 피처 중요도 5위 (0.092)
tg_news_ratio    → 피처 중요도 6위 (0.086)
```

- AUC 0.572 → **0.6053** (+0.033): 텔레그램 3개 피처가 상위 6위 내 모두 진입
- 뉴스 대비 텔레그램 언급량이 급증하는 구간이 주가 과열 선행 신호로 작동

**tg_news_ratio 실제 과열 사례**

| 테마 | 기간 | 텔레그램 언급 | 뉴스 수 | tg_news_ratio | 해석 |
|------|------|------------|---------|--------------|------|
| 스페이스X | 2025-11 | 21건 | 41건 | 0.51 | 정상 |
| 스페이스X | 2025-12 | **91건** | 41건 | **2.17** | 과열 시작 |
| 스페이스X | 2026-01 | **112건** | 50건 | **2.20** | 과열 지속 |
| HBM | 2025-07 | 156건 | 38건 | **3.97** | 과열 |
| HBM | 2026-01 | 234건 | 40건 | **5.71** | 극과열 |
| HBM | 2026-05 | **286건** | 48건 | **5.84** | 역대 최고 |

**스페이스X 사례 해석:**
```
2025-11  텔레그램 21건 → 뉴스 41건 → ratio 0.51 (정상)
2025-12  텔레그램 91건 → 뉴스 41건 → ratio 2.17 (텔레그램이 뉴스의 2배 폭증)
2026-01  텔레그램 112건 → 뉴스 50건 → ratio 2.20 (과열 지속)
         → 뉴스 감성 기반 테마 선정에서 스페이스X 1위 선정
         → 한화에어로스페이스 종합점수 0.575 (스페이스X 1위 관련주)
```
텔레그램 과열(ratio > 2.0)이 공식 뉴스 집중보다 선행했고, 이후 테마 선정 및 관련주 상승으로 이어짐.

| 두나무 | 0개 | KRX500 4개 | 코오롱, 카카오, 한화투자증권 |
| 리츠 | 0개 | KRX500 5개 | 롯데리츠, SK리츠, ESR켄달스퀘어리츠 |

### 4. Gemini LLM 감성 분석 효과

```
키워드 방식: "상승 기대감 꺾여" → '상승' 키워드 → 긍정 (오분류)
Gemini LLM:  "상승 기대감 꺾여" → 전체 맥락 → 부정 (정확)
```

- 중립 72% → 18% (유의미한 감성 정보 대폭 증가)
- 긍정 20% → 63% (문맥 기반으로 실제 호재 기사 식별)

## 분석 방법론

### 종합점수 계산식

```
종합점수 = 상승확률 × 0.6 + 감성-수익률 상관관계(정규화) × 0.4
```

- **상승확률**: XGBoost가 예측한 익일 상승 확률의 종목별 평균
- **감성-수익률 상관관계**: Gemini 감성이 긍정일 때 다음날 주가가 실제로 올랐는지의 역사적 일치율

### 뉴스 기반 테마 선정 방식

```
후보 TOP10 (텔레그램 언급 빈도) → 뉴스 수집 → Gemini 감성 분석
         ↓
테마 감성점수 = 긍정비율 × 0.6 + 정규화 총합 × 0.4
         ↓
상위 TOP5 → 최종 분석 대상
```
