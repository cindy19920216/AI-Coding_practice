# 한국 주식 테마 감성 분석 → 핵심 관련주 발굴 파이프라인

> 텔레그램 채널 데이터 기반으로 월별 주도 테마를 추출하고,  
> **Gemini LLM 감성 분석** + XGBoost로 테마에 가장 민감하게 반응하는 관련주를 자동 발굴합니다.

---

## 핵심 아이디어

```
"2차전지 관련 뉴스가 긍정적이다" (Gemini LLM 문맥 감성 분석)
         ↓
그 시점에 실제로 주가가 올랐나? (yfinance 검증)
         ↓
긍정 뉴스 + 주가 상승이 일치하는 종목 = 핵심 관련주
         ↓
"이 테마에서 가장 민감하게 반응하는 기업은 A, B, C다" (XGBoost 랭킹)
```

---

## 전체 흐름 (7 STEP)

```
STEP 1  텔레그램 CSV 로드
        └─ 10개 채널 메시지에서 월별 TOP5 테마 추출
           노이즈 복합어 제거 후 순수 테마 언급만 카운트

STEP 2  Google 뉴스 자동 수집
        └─ 월별 TOP5 × 12개월 = 최대 60개 쿼리
           pygooglenews 사용, API키 불필요
           총 2,258건 수집

STEP 3  Gemini LLM 감성 분석 ★ 핵심 개선
        └─ 키워드 방식(중립 72%) → Gemini LLM 문맥 이해(중립 18%)
           "상승 기대감 꺾여" → 부정 / "하락 우려 해소" → 긍정
           모델: gemini-3.1-flash-lite / 배치 20건 / 5회 재시도

STEP 4  yfinance 주가 데이터 수집
        └─ KRX300 기준 시총 상위 300종목만 대상
           FinanceDataReader 기반 (KOSPI+KOSDAQ 시총 상위 300종목)

STEP 5  감성점수 + 주가 수익률 병합
        └─ 뉴스 감성(t일) → 익일 주가 수익률(t+1일) 매핑
           3일·5일 이동평균 감성점수 추가

STEP 6  XGBoost 예측 (TimeSeriesSplit 5-fold)
        └─ 익일 주가 상승 여부(up_next) 분류
           평균 AUC: 0.5723

STEP 7  최종 관련주 랭킹 + 시각화 7종
        └─ 종합점수 = 상승확률(60%) + 감성-수익률 상관관계 정규화(40%)
```

## 시사점

### 1. Gemini LLM 도입 효과

키워드 방식의 가장 큰 한계는 **문맥 이해 불가**였습니다:

```
키워드 방식: "상승 기대감 꺾여" → '상승' 키워드 → 긍정 (오분류)
Gemini LLM:  "상승 기대감 꺾여" → 전체 맥락 → 부정 (정확)
```

결과:
- 중립 72% → 18% (유의미한 감성 정보 대폭 증가)
- 긍정 20% → 63% (문맥 기반으로 실제 호재 기사 식별)
- `news_count` 피처 중요도 상승: 뉴스 보도량 자체가 예측력을 가짐

### 2. 통신주가 자꾸 상위에 나오던 이유 (해결)

"통신"이라는 단어가 위성통신(스페이스X 관련), 통신모듈(로봇·IoT), 광통신(HBM) 등 다른 테마 메시지에서 복합어로 오염됐었습니다.

| 월 | 원본 언급 | 노이즈 제거 후 | 제거율 |
|----|-----------|----------------|--------|
| 2026-03 | 85건 | 58건 | 32% |
| 2026-04 | 76건 | 53건 | 30% |
| 2025-09 | 31건 | 15건 | 51% |

**남아있는 통신 언급은 실제 SKT·KT·LGU+ 직접 언급** — Gemini 감성 분석에서 통신주 뉴스는 감성상관이 음수(-0.2~-0.3)로 부정적 뉴스 비중이 높음을 확인.

### 3. KRX300 필터 전후 비교

| 테마 | 전체 종목 | KRX300 필터 후 | 주요 제거 유형 |
|------|-----------|----------------|----------------|
| 로봇 | 70개 | 12개 | 소형 부품·로봇주 |
| 화장품 | 91개 | 14개 | 소형 ODM·원료주 |
| HBM | 33개 | 9개 | 소형 장비·소재주 |
| 통신 | 3개 | 3개 | 변동 없음 (전부 대형주) |

### 4. 대형주와 감성 추세의 관계

소형주 포함 이전 실행에서는 `return_1d`(주가 모멘텀)가 피처 중요도 1위였으나,  
KRX300 대형주 기준에서는 `sentiment_ma3`(3일 감성 추세)가 1위.  
**대형주는 기관·외국인 매매 비중이 높아 뉴스 감성이 추세적으로 누적됨.**

### 5. AUC 해석

| 구분 | AUC | 의미 |
|------|-----|------|
| 랜덤 예측 | 0.500 | 기준선 |
| 키워드 감성 | 0.583 | 랜덤 대비 16.6% 개선 |
| **Gemini 감성** | **0.572** | 랜덤 대비 14.4% 개선 |

> Gemini 도입 후 AUC가 소폭 하락했으나, 이는 **감성 정보가 더 다양해져** 모델이 단순 패턴을 학습하기 어려워진 것으로 해석됨. 감성점수 품질은 향상됐으나 추가 피처(거래량, 52주 고저, 코스피 상대 강도) 보강이 필요.

### 6. 한계 및 개선 방향

| 우선순위 | 항목 | 개선 방법 |
|---------|------|-----------|
| 🔴 완료 | 감성 분석 품질 | Gemini LLM 도입 (중립 72%→18%) |
| 🔴 완료 | 대형주 필터 | KRX300 기준 적용 |
| 🔴 완료 | 테마 노이즈 | 통신·은행 복합어 제거 |
| 🟡 권장 | 피처 보강 | 거래량 변화율, 52주 고저, KOSPI 상대강도 추가 |
| 🟡 권장 | 뉴스 수집량 | BATCH_SIZE 100~200, 네이버 뉴스 추가 |
| 🟢 선택 | 모델 고도화 | LSTM 또는 앙상블로 시계열 구조 반영 |

## 분석 방법론

### 종합점수 계산식

```
종합점수 = 상승확률 × 0.6 + 감성-수익률 상관관계(정규화) × 0.4
```

- **상승확률**: XGBoost가 예측한 익일 상승 확률의 종목별 평균
- **감성-수익률 상관관계**: Gemini 감성이 긍정일 때 다음날 주가가 실제로 올랐는지의 역사적 일치율

### Gemini 감성 분석 방식

```
입력: 뉴스 기사 제목 + 요약 (20건씩 배치)
출력: 긍정(1) / 부정(-1) / 중립(0)

핵심 프롬프트:
- "상승 기대감 꺾여" → 부정
- "하락 우려 해소" → 긍정
- 부정어 + 긍정단어 조합 → 전체 문맥 우선
```

### KRX300 근사 방법

| 구분 | 방법 | 비고 |
|------|------|------|
| 이상적 | pykrx KRX300 index | pykrx 1.2.4에서 API 깨짐 |
| 현재 사용 | FinanceDataReader 시총 상위 300 | 최소 시총 약 1.32조원 기준 |
